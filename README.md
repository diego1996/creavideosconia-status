# Estado de CreaVideosConIA

Página pública: **https://status.creavideosconia.com**

Este repositorio solo contiene la configuración y el historial de disponibilidad (sin código de la plataforma).
[Upptime](https://upptime.js.org) revisa cada 5 minutos, desde GitHub Actions, el sitio, el Studio, la API, la
producción de vídeos, la publicación, los pagos y la conexión MCP. Cada caída abre un incidente con su historial.
